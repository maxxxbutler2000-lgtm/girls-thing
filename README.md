# The Dorado Beach Sitters

A colorful, mobile-friendly babysitting website for Teagan, Laura, and Anna in Dorado Beach.

- Introductions for all three sitters
- Interactive crafts, story time, games, and dance activity ideas
- Babysitting rate: $20 per hour
- Parent or guardian coordinated booking information

Open `index.html` in a browser to view the website. No installation or build step is needed.

The booking contact has not been added yet. All arrangements must be confirmed with a parent or guardian.
